# Logo source files

Original generated artwork the current identity was derived from.

`ChatGPT Image ... (4).png` is the master — it is the flat, un-glowed sheet.
The car glyph was traced to vector from the monochrome white version on
sheet (3), which was the largest clean instance at 326px.

These live outside `public/` on purpose: anything in `public/` is served on
the live site, and these are working files, not site assets.

Brand colours sampled from this artwork:

- Graphite `#131A1E`
- Orange   `#FC6704`

Derived assets live in `public/` (`mark.svg`, `logo-mark.svg`,
`logo-header-*.png`, `logo-footer-*.png`, `icon-*.png`, `logo-og.png`,
`logo-square.png`, `apple-touch-icon.png`) and `src/app/favicon.ico`.
